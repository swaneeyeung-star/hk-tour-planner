# hk-tour-planner

Sai Kung (香港西貢) walking-route planner web app — a single-file HTML app with dynamic route generation, simulated first-person walks, in-page restaurant reviews with photo proof, mascot collection, and a 7-language UI (English, 繁體中文, 简体中文, Français, 日本語, 한국어, Español).

**Live site:** https://sites.hellominds.ai/scubavo.tuff/hk-tour-planner/index.html

## What's inside
- 42 real, verified Sai Kung restaurants with source-labelled ratings (blank where no published rating exists — nothing invented)
- Pins geocoded to building level from OpenStreetMap; team-reported misplacements fixed (nothing sitting on water)
- Guest-mode sign-in from the map sidebar; progress carries over on account creation
- Browser-local accounts (no backend), private saved routes

## Build history
The app is one ~1.3MB HTML file, so every build is attached as `index.html` on a GitHub Release — see the [Releases page](https://github.com/swaneeyeung-star/hk-tour-planner/releases) for the exact source of each build. Every future build gets a new release here.

## Team workflow
Bug reports from the team are tracked as GitHub issues. Request a change in the team email thread and it lands in the next build + release.
